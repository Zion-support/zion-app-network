## Shared content pattern

1. Accurate page title and document language.
2. Clear description of what is implemented, what is only a concept, and what requires integration.
3. Consistent Home / Free Discovery / Apps / Start Here navigation.
4. Relevant related-app links; use a hub instead of an unreadable all-to-all list.
5. Available same-page translations only. Never label an English fallback as translated.
6. Keyboard-visible focus, mobile-friendly layout and descriptive link text.
7. Human review, scope limits and a stop rule for operational or regulated workflows.
8. Canonical URL and reciprocal `hreflang` for new translated pages.

## Free Discovery delivery contract

The browser report is immediate and free. FormSubmit receives a request to deliver the same report to `commercial@ziontechgroup.com`, copying the validated client email. Provider acceptance is not confirmed inbox receipt. Preserve copy/download and manual fallback options. Do not claim zero downtime or guaranteed instant email. Do not add recipients without a documented decision.

## Counts and evidence

[Coverage manifest](https://ziontechgroup.com/apps/network-publication-coverage.json) reports HTML routes and existing language counterparts in the production artifact. It is NOT a count of functional AI apps and does not cover separately hosted repositories. Counterpart existence alone does not certify semantic translation quality.

The same historical batch number is currently used for different themes across files. Use descriptive slugs and repository identifiers when linking; reconcile historical batch labels before advertising a new batch total.

## Release checklist

- [ ] Source changes reviewed against current `main`.
- [ ] Five language variants generated and checked.
- [ ] Navigation routes exist in the built artifact.
- [ ] Forms preserved; no unintended sends, purchases or uploads.
- [ ] GitHub Pages deployment observed.
- [ ] Fresh public HTTP 200 and release markers verified.
- [ ] Translation gaps recorded, not concealed.
- [ ] Notion CEO status and Supermemory checkpoint updated.
