## Publication contract

Production uses `public/` plus artifact renderers in the homepage repository. This release consolidates two editorial guides; it does not create functioning AI engines or dispatch systems. Verify public release markers after the GitHub Pages build.

Each guide has localized body content, canonical metadata, six head alternates, a five-language switcher, a companion-guide link, curated app/source links and the same responsive layout. Five localized homepage promotions and reciprocal links on three artifact-hosted tools preserve original forms byte-for-byte. Independently hosted repositories are not claimed migrated.
