# Field Service Evidence Guide — five-language release directory

Release source: [homepage commit 509a3b9](https://github.com/Zion-support/zion-support.github.io/commit/509a3b9aa529ffb5a518973ac18d19cfa3ead0cf).

## English
[Field Service Evidence Guide](https://ziontechgroup.com/apps/field-service-evidence-guide.html): specify scope, qualify written supplier evidence, compare complete costs, obtain approval and close with evidence. A guide is not a supplier commitment, purchase order or dispatch authorization.

## Português
[Guia de evidências para serviços de campo](https://ziontechgroup.com/apps/field-service-evidence-guide.pt-br.html): documente o escopo, valide evidências escritas do fornecedor, compare custos completos, obtenha aprovação e registre resultados. O guia não confirma fornecedor, compra ou despacho.

## Español
[Guía de evidencias para servicios de campo](https://ziontechgroup.com/apps/field-service-evidence-guide.es.html): defina el alcance, valide evidencias escritas, compare costes completos, obtenga aprobación y documente resultados. La guía no confirma proveedores, compras ni desplazamientos.

## Français
[Guide des preuves pour les services sur site](https://ziontechgroup.com/apps/field-service-evidence-guide.fr.html) : précisez le périmètre, vérifiez les preuves écrites du fournisseur, comparez les coûts complets, obtenez l’approbation et documentez les résultats. Le guide ne confirme ni fournisseur, ni achat, ni intervention.

## Deutsch
[Leitfaden für Nachweise bei Vor-Ort-Services](https://ziontechgroup.com/apps/field-service-evidence-guide.de.html): Umfang festlegen, schriftliche Lieferantennachweise prüfen, vollständige Kosten vergleichen, Freigabe einholen und Ergebnisse dokumentieren. Der Leitfaden bestätigt weder Lieferant noch Bestellung oder Einsatz.

## Publication and capability boundaries
Production is built from `public/` plus artifact renderers; committing a root Markdown file to the homepage repository does not publish a website page. This document is a GitHub directory, not independent proof that the linked deployment is live.

The approved renderer adds reciprocal five-language navigation, hreflang/canonical links and homepage promotions. Offline tests passed; consult [deployment](https://github.com/Zion-support/zion-support.github.io/actions/runs/37868715436) and [read-only release QA](https://github.com/Zion-support/zion-support.github.io/actions/workflows/field-evidence-release-qa.yml) for current publication evidence.

Discovery recommendation types distinguish service pages, documentation/concepts, calculators requiring assumption validation and unverified destinations. HTTP 200 confirms retrieval, not functional capability. Email routing remains participant plus Commercial; provider acceptance is not paired inbox receipt.

Network-wide translations, inventory reconciliation and capability/interlink audits remain a backlog. Do not infer all repositories or pages were checked from this five-guide release.
