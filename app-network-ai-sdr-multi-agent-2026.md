# App Network — New Concept App: AI SDR & Multi-Agent Lead Agent

**Cluster:** Sales & Lead Generation · **Batch:** 125 (2026-11-14) · **Status:** Published (5-language HTML) + repo in GitHub  
**Owner:** Zion Tech Group · **Lead:** Apollo specialist + SalesOps

## 1. Purpose

A free, always-online **AI SDR & Multi-Agent Lead Agent** hub: the intelligence layer for account-based
outbound. It combines (a) the lead-engineering pipeline from Batch 123 (email-thread lead scanner + enrichment +
CRM write-back) with (b) multi-agent orchestration — prospector, enrichment, personalization, sequencing, reply
handling, and qualification. It is the "search emails for leads, contact them offering services, extract contacts to
CRM/HubSpot, follow up" workflow, automated into a multi-agent system.

## 2. Why now (market signal)

- AI email agents (Ava, Alice, Jason, Agent Frank, Agent A/Ahrefs) automate the full outbound pipeline: lead
  sourcing → enrichment → personalised email → follow-up sequencing → reply handling → qualification → meeting booking.
- Multi-agent workflows operate in parallel (prospector, enrichment, writer, sequencer, inbox, qualification) with
  human-in-the-loop review — cutting outreach time from 10–15 minutes to 3–5 minutes per account.
- The highest-value data is the company's own email thread history plus external intent signals; combining them
  compounds ROIs.

## 3. Core features

1. **Multi-agent orchestrator** — prospector (find ICP-matched leads), enrichment (verified contact + firmographics),
   writer (personalised outreach calibrated to signal), sequencer (multi-step follow-up), inbox (classify replies),
   qualification (score + route to meeting booking).
2. **Signal-calibrated outreach** — every email references the specific intent signal + prior company engagement
   history, with human review (3–5 min/account).
3. **CRM write-back** — full conversation context attached to contact records (HubSpot), so reps walk into calls
   with the complete picture.
4. **Meeting booking** — AI books confirmed leads directly via calendar integration.
5. **Discovery handoff** → agent marketplace (Batch 117) + implementation vault (Batch 121) + vertical trust (Batch 122).
