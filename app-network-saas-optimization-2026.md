# App Network — New Concept App: SaaS Optimization & ROI Calculator (FinOps)

**Cluster:** FinOps / Cost Analytics · **Batch:** 119 (2026-11-14) · **Status:** Published (5-language HTML) + repo in GitHub  
**Owner:** Zion Tech Group · **Lead:** SalesOps + Data

## 1. Purpose

A free, always-online **SaaS Optimization & ROI Calculator**: quantifies the cost waste in a client's software and
AI stack — unutilized seats, idle cloud spend, redundant subscriptions, over-provisioned agents — and models the
payback of right-sizing, deprovisioning, and migrating. This is the FinOps entry point into the apps network, owned
by the discovery team and advertised on the homepage.

## 2. Why now (market signal)

- SaaS optimization ROI = realized cost savings / implementation cost. Even a 20% reduction on a $200–500k/mo
  SaaS spend is $40–100k/month — the clearest, most auditable ROI in the entire apps network.
- AI spend is rising faster than ML observability; clients need a consolidated cloud + SaaS + AI cost view.
- This cluster is complementary to the financial/lead tools (FinOps Cluster 1/114) and to the agent marketplace.

## 3. Core features

1. **License waster audit** — unutilized seats, SSO inactivity, redundant subscriptions.
2. **Cloud spend modeler** — idle instances, over-provisioned agents, commitment gap.
3. **Payback estimator** — right-sizing + deprovisioning ROI with 90-day quick-win targets.
4. **LLM cost optimizer** — prompt caching, token efficiency, run cost per 1,000 calls.
5. **Export** — ROI PDF (Zion logo) to share with CFOs/ops leads.
6. **Discovery handoff** — waste report → paid diagnostic sprint (Batch 116) → implementation.

## 4. Pricing & markup (Zion)

- **ROI calculator:** free, always online (audit + modeler + payback).
- **Optimization engagement:** priced per engagement, **minimum 40% markup over all-in cost for Zion**.
- No order begins without client written confirmation + PO.

## 5. Discovery & pitch

- Free Discovery questionnaire → ROI calculator → your wasted-software-and-AI-cost report → paid optimization.
- Pitch: "Find the $ you're leaking in subscriptions and cloud — before we fix it."
