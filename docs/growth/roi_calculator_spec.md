# Zion ROI Calculator - Specification

## Inputs (from Discovery)
- industry, company size, service/process selected, challenge description
- timeline, budget confirmation, readiness signals (e.g., already using AI tools)

## Outputs (indicative)
- Expected cost range (service) - required to get from Date A to Date B
- Time savings (hours per week)
- Revenue uplift / risk reduction (custom, based on industry benchmarks)
- Payback period (months)

## Constraints
- Outputs are estimates, not quotes or guarantees
- Defaults: all zero if fields omitted; no client data sent to the calculator
- Labels: estimates, assumption-based, non-binding

## Reference
- Use Phar 80, Block 13 metrics: cost-to-save, time-to-value, payback
- Exclude computed results for Prior Training, Retention, and web administration
