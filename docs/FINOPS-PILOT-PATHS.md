## Publication contract
The website repository generates these canonical pages under `/zion-app-network/`; this repository records the multilingual navigation and source contract, not a duplicate independent runtime. [Renderer source](https://github.com/Zion-support/zion-support.github.io/blob/main/scripts/render-finops-hub.cjs) · [Acceptance tests](https://github.com/Zion-support/zion-support.github.io/blob/main/scripts/test-finops-hub.cjs) · [Publication manifest](https://ziontechgroup.com/apps/finops-hub-publication.json).

Scope: five hub guides, five homepage links, twenty reciprocal resource links and ten calculator/guide returns. Publication requires successful deployment and fresh public-marker checks. A reachable guide is not a full app-functionality audit. Full-network translations and interlinks remain incomplete; historical app counts are not used as verified capability counts. No email/form submission, payment, cloud scan or financial advice.
