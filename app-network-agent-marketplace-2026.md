# App Network — New Concept App: Agent Marketplace (SMB Agent Catalog)

**Cluster:** Marketplace / Integrator · **Batch:** 117 (2026-11-14) · **Status:** Published (5-language HTML) + repo in GitHub  
**Owner:** Zion Tech Group · **Lead:** Partnerships + ContentPublisher

## 1. Purpose

A curated, always-online marketplace of narrow, pre-configured AI agents for SMB workflows — service triage,
quote follow-up, review response, appointment reminders — with human-in-the-loop approval before anything ships.
Built for the SEO/GEO growth team and the local-services clients who need "automation without an AI engineering team."

## 2. Why now (market signal)

- Ready-to-deployed workflow agents represent ~45% of 2026 marketplace revenue; buyers prefer identifiable tasks
  (service triage, document processing, software operations) over unconfigured building blocks.
- Marketplace models grow via: a discovery/catalog layer, a verification/benchmarking layer, a deployment layer,
  a billing layer, and a governance layer.
- For a services-led firm like Zion, the most valuable vertical is the local-services workflow (triage, callbacks,
  quotes, reviews) — the same friction the Batch 115 voice cluster already owns.
- Agent-as-a-Service / marketplace / per-agent subscription models all fit a services-led merchant without an
  AI-engineering war chest.

## 3. Catalog of pre-configured agents (v1)

1. **Service Triage Agent** — answers the phone, logs the job type, routes to the right dispatcher.
2. **Quote Follow-Up Agent** — texts/app-SMS the 48-hour follow-up on every unquoted estimate.
3. **Review Response Agent** — drafts SEO/GEO-optimized responses to every new review (Airbnb, Google, Facebook).
4. **Appointment Reminder Agent** — texts + WhatsApp reminders 24h and 2h before, with resend on no-show.
5. **Google Business Profile Agent** — publishes updates, monitors mentions, appeals suspensions.

## 4. Marketplace mechanics (the minimum viable layer)

- **Discovery/catalog** — clients browse by workflow + industry (local services, trades, contractors).
- **Verification & benchmarking** — each agent is scored on accuracy, latency, and human-approval rate before listing.
- **Deployment** — click-to-configure agent into the client's existing stack (Zion CRM, HubSpot, or their own).
- **Billing** — per-agent subscription or usage-based ($49-$299/agent/month, free for the first 100 transactions).
- **Governance** — audit logs, access controls, human-approval rules; no agent ships without an approval sign-off.

## 5. Pricing & markup (Zion)

- **Agent subscriptions:** shared with clients; **minimum 40% markup over all-in cost for Zion**.
- **Commission on marketplace sales:** 20% platform fee on agent fees (first 6 months free to seed the catalog).
- No flow ships into a client's stack without client confirmation + PO.

## 6. Discovery & pitch

- Free Discovery questionnaire → agent-marketplace catalog → client picks a workflow → 10-minute setup session.
- Pitch: "Find the one workflow that costs you the most hours. We give you a vetted agent for it — configure, approve, go."
