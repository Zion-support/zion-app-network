Put the guide into practice

  1. Choose one outcome

    Name the task, owner and preferred language. Use the collection matching that task.

  2. Check what the resource does

    Read the capability description and source evidence. A guide, local calculation and connected service require different checks.

  3. Carry the result forward

    Keep the assumptions and open questions with the result. Ask the responsible person to review the next step before acting.

Worked example

Example: prepare a switch replacement

For a fictional maintenance visit, start with the handoff checklist to review scope, access and parts. Use the operations checklist to define the expected connectivity tests, then the completion pack to record results, open issues and customer acceptance separately. For one site or several, document the actual visit sequence and approved scope before any additional commitment.

What this guide covers

The navigation and featured guides are available in five languages. Source indexes and older destinations may use English or mixed languages; each link identifies that scope. Review a resource’s stated capabilities before using its output.
