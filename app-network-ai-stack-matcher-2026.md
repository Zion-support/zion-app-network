# App Network — New Concept App: AI Stack Matcher

**Cluster:** AI Technology Selection / Consulting · **Batch:** 118 (2026-11-14) · **Status:** Published (5-language HTML) + repo in GitHub  
**Owner:** Zion Tech Group · **Lead:** Apollo specialist + Engineering

## 1. Purpose

A free, always-online **AI stack matcher**: turns a client's workforce and workflow description into a scored,
confidence-rated recommendation on whether to build / blend / buy an AI capability — with a 3-year TCO model and a
portability ramp. The sale-matching tool is the top-of-funnel: it is free, instant, and hands the client a decision
ready for implementation (Batch 116: diagnostic sprint; Batch 117: agent marketplace).

## 2. Why now (market signal)

- AI technology selection consulting is the fastest-growing entry point for AI deals (build/blend/buy verdicts,
  3-year TCO, orchestration comparison).
- Clients are overwhelmed by tool choice; a scored recommendation on their own workload converts far better than a
  generic catalog.
- This cluster complements the diagnostic sprint (which finds the bottleneck) and the agent marketplace (which
  deploys the solution).

## 3. Core features

1. **Workforce & workflow intake** — free 5-question form: team size, primary manual tasks, compliance needs, cloud
   posture, budget band.
2. **Scored matching** — returns a ranked stack recommendation (build / blend / buy) per workload, with confidence.
3. **3-year TCO model** — per candidate, including integration and exit costs.
4. **Orchestration comparison** — LangChain vs LangGraph vs crewAI vs custom, matched to team.
5. **Portability ramp** — from vendor lock-in to self-host, with runbooks.
6. **Discovery handoff** — the matched stack → paid discovery sprint (Batch 116) → implementation.

## 4. Pricing & markup (Zion)

- **Stack matcher:** free, always online (intake + scored matching + TCO).
- **Selection Scan / Evaluated Selection:** priced per engagement, **minimum 40% markup over all-in cost for Zion**.
- No implementation begins without client written confirmation + PO.

## 5. Discovery & pitch

- Free Discovery questionnaire → stack matcher → your personalised AI-stack recommendation → paid discovery + implementation.
- Pitch: "Tell us what you do. We tell you whether to build, blend, or buy AI — with the 3-year cost model."
